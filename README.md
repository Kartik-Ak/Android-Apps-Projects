## 🚫 Spam Detector App

This was one of my first Android projects focused on detecting spam messages or unwanted content using a **web-based API**.

### 📱 Features:
- Detects spam by matching common keywords (like "win", "free", "urgent")
- Sends message content to an API for advanced spam analysis (server-side filtering)
- Flags and displays suspicious messages with clear UI

### 🌐 API Integration:
The app communicates with an external API to check message content for potential spam. This helped in:
- Understanding how to make network requests in Android using Retrofit/Volley (whichever you used)
- Learning how to send and receive JSON data
- Handling API responses and displaying results in real-time

### 🎯 Purpose:
This app was built to explore:
- Android networking (API calls)
- Permissions and content filtering
- UI layout and state handling

### 🔍 Notes:
- The API used may have limited access or demo quota
- The spam logic can be enhanced by training better models or adding regex filters
- UI is built for phones and may not be optimized for all screen sizes

📌 *This project helped me understand both frontend logic and backend API communication — a big step in my Android learning journey.*
